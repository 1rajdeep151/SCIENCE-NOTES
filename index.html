Lesson 1 / পাঠ ১

Atomic structure: what is an atom?

পরমাণুর গঠন: পরমাণু কী?

An atom is the smallest unit of an element that retains its chemical identity. Its tiny, dense nucleus contains positively charged protons and neutral neutrons. Negatively charged electrons occupy regions around the nucleus.

পরমাণু হলো কোনো মৌলের এমন ক্ষুদ্রতম একক যা মৌলটির রাসায়নিক পরিচয় বজায় রাখে। এর ক্ষুদ্র ও ঘন নিউক্লিয়াসে ধনাত্মক প্রোটন এবং আধানহীন নিউট্রন থাকে। ঋণাত্মক ইলেকট্রন নিউক্লিয়াসের চারপাশের অঞ্চলে অবস্থান করে।

Schematic only — not to scale; electron paths are not literal tracks.
শুধু ধারণামূলক ছবি—আসল মাপ অনুযায়ী নয়; ইলেকট্রন নির্দিষ্ট পথে ঘোরে এমন নয়।

Atomic number (Z) = number of protons. For a neutral atom, electrons = protons. Mass number (A) = protons + neutrons.

পারমাণবিক সংখ্যা (Z) = প্রোটনের সংখ্যা। নিরপেক্ষ পরমাণুতে ইলেকট্রন = প্রোটন। ভরসংখ্যা (A) = প্রোটন + নিউট্রন।

Lesson 2 / পাঠ ২

Energy shells: the principal quantum number n

শক্তিস্তর বা Shell: প্রধান কোয়ান্টাম সংখ্যা n

A shell is a main energy level. It is identified by the principal quantum number n = 1, 2, 3, 4… and commonly named K, L, M, N… respectively. Larger n generally means higher energy and a greater average distance from the nucleus for hydrogen-like orbitals.

Shell হলো প্রধান শক্তিস্তর। এর পরিচয় নির্ধারণ করে প্রধান কোয়ান্টাম সংখ্যা n = 1, 2, 3, 4…; এগুলিকে যথাক্রমে K, L, M, N… বলা হয়। সাধারণভাবে n বাড়লে শক্তি বাড়ে এবং নিউক্লিয়াস থেকে গড় দূরত্বও বাড়ে।

Lesson 3 / পাঠ ৩

Subshells: the azimuthal quantum number l

উপশক্তিস্তর বা Subshell: আজিমুথাল কোয়ান্টাম সংখ্যা l

Each shell contains one or more subshells. For a given n, allowed values are l = 0 to n−1. The letters are s, p, d, f for l = 0, 1, 2, 3. Each subshell has a characteristic orbital shape family and capacity.

প্রতিটি shell-এ এক বা একাধিক subshell থাকে। নির্দিষ্ট n-এর জন্য l = 0 থেকে n−1 পর্যন্ত মান সম্ভব। l = 0, 1, 2, 3 হলে যথাক্রমে s, p, d, f। প্রতিটি subshell-এর orbital-এর নির্দিষ্ট আকৃতি-ধরন ও ধারণক্ষমতা আছে।

SubshelllOrbitals = 2l+1Max electronsSimple shape cue
s012Spherical / গোলাকার
p136Dumbbell / ডাম্বেল-আকৃতি
d2510Mostly clover-like / অধিকাংশ ক্লোভার-আকৃতি
f3714More complex / জটিল আকৃতি
s: spherical probability region / গোলাকার সম্ভাব্যতার অঞ্চল
p: two-lobed shape family / দুই-লোব বিশিষ্ট
Counting rule: one orbital holds at most 2 electrons. Thus s: 1×2=2; p: 3×2=6; d: 5×2=10; f: 7×2=14.
গণনার নিয়ম: একটি orbital-এ সর্বোচ্চ ২টি ইলেকট্রন থাকে। তাই s: ১×২=২; p: ৩×২=৬; d: ৫×২=১০; f: ৭×২=১৪।
Lesson 4 / পাঠ ৪

The four quantum numbers — four separate visual guides

চারটি কোয়ান্টাম সংখ্যা — প্রতিটির আলাদা চিত্র

A quantum number is a value used to describe a particular electron state in an atom. For one electron, we specify n, l, mₗ and mₛ.

কোয়ান্টাম সংখ্যা হলো পরমাণুতে একটি ইলেকট্রনের অবস্থা বর্ণনা করার মান। একটি ইলেকট্রনের জন্য n, l, mₗ এবং mₛ নির্দিষ্ট করা হয়।

1) Principal quantum number (n) / প্রধান কোয়ান্টাম সংখ্যা

n = 1, 2, 3, …

Tells you: the main shell/energy level. Larger n generally indicates a higher shell.

কী জানায়: প্রধান shell বা শক্তিস্তর। সাধারণভাবে n যত বড়, shell তত বাইরের দিকে।

2) Azimuthal quantum number (l) / আজিমুথাল কোয়ান্টাম সংখ্যা

l = 0 … n−1

Tells you: subshell type / orbital angular momentum. l=0→s, 1→p, 2→d, 3→f.

কী জানায়: subshell-এর ধরন। l=0→s, 1→p, 2→d, 3→f।

3) Magnetic quantum number (mₗ) / চৌম্বকীয় কোয়ান্টাম সংখ্যা

mₗ = −l … 0 … +l

Tells you: the orbital orientation label. For p (l=1): mₗ = −1, 0, +1 — three allowed values/orbitals.

কী জানায়: orbital-এর orientation। p subshell-এ (l=1) mₗ = −1, 0, +1 — মোট তিনটি অনুমোদিত মান/orbital।

The drawing is conceptual: mₗ values label allowed orbital states; they are not literal compass directions in every atom.

চিত্রটি ধারণামূলক: mₗ orbital state নির্দেশ করে; সব ক্ষেত্রে একে সরাসরি কম্পাসের দিক ভাবা যাবে না।

4) Spin quantum number (mₛ) / স্পিন কোয়ান্টাম সংখ্যা

mₛ = +½ or −½

Tells you: the electron's spin state. Two electrons in the same orbital must have opposite spins.

কী জানায়: ইলেকট্রনের spin state। একই orbital-এ থাকা দুই ইলেকট্রনের spin বিপরীত হতে হবে।

Lesson 5 / পাঠ ৫

How to write an element/electron correctly using quantum numbers

কোয়ান্টাম সংখ্যা ব্যবহার করে মৌল/ইলেকট্রনের সঠিক সংকেত কীভাবে লিখবেন

Two different notations are often confused. Nuclide notation identifies an atom using mass number and atomic number; quantum-number notation specifies the state of one electron. They are not the same thing.

দুটি সংকেত প্রায়ই গুলিয়ে ফেলা হয়। নিউক্লাইড সংকেত ভরসংখ্যা ও পারমাণবিক সংখ্যা দিয়ে পরমাণুকে চিহ্নিত করে; কোয়ান্টাম-সংখ্যার সেট একটি ইলেকট্রনের অবস্থা বোঝায়। দুটি এক জিনিস নয়।

AZX    and    (n, l, mₗ, mₛ)

Example A: sodium atom / উদাহরণ A: সোডিয়াম

2311Na

Z=11 means 11 protons; A=23 means protons + neutrons = 23, so neutrons = 12. A neutral atom has 11 electrons. Ground-state configuration: 1s² 2s² 2p⁶ 3s¹.

Z=11 অর্থ ১১টি প্রোটন; A=23 অর্থ প্রোটন + নিউট্রন = ২৩, তাই নিউট্রন = ১২। নিরপেক্ষ পরমাণুতে ১১টি ইলেকট্রন। ভূমিস্তরের বিন্যাস: 1s² 2s² 2p⁶ 3s¹।

Example B: last electron in Na / Na-এর শেষ ইলেকট্রন

(n, l, mₗ, mₛ) = (3, 0, 0, +½)

The last electron is in 3s: n=3; s means l=0; when l=0, mₗ=0; the single electron may be assigned mₛ=+½ by a stated convention (the opposite sign is also a possible spin label for an isolated orbital electron).

শেষ ইলেকট্রন 3s-এ: n=3; s হলে l=0; l=0 হলে mₗ=0; একক ইলেকট্রনের জন্য প্রচলিত convention-এ mₛ=+½ লেখা যায় (spin label হিসেবে −½-ও সম্ভব)।

Worked example: one electron in 4f / 4f-এ একটি ইলেকট্রন

1
n = 4 because the shell is the fourth / চতুর্থ shell, তাই n=4।
2
l = 3 because f corresponds to l=3 / f-এর জন্য l=3।
3
mₗ = −3, −2, −1, 0, +1, +2, +3 / এই সাতটি পূর্ণসংখ্যার যেকোনো একটি।
4
mₛ = +½ or −½ / spin-এর দুটি মান।
One valid set / একটি বৈধ সেট: (4, 3, +1, +½). Not every combination is valid: for example, l cannot equal 4 when n=4, and mₗ cannot be +4 for l=3.

Quick validity checklist

সঠিকতা যাচাইয়ের তালিকা

  • n must be a positive integer: 1, 2, 3… / n ধনাত্মক পূর্ণসংখ্যা।
  • l must satisfy 0 ≤ l ≤ n−1 / l-এর মান ০ থেকে n−১।
  • mₗ must be an integer from −l to +l / mₗ হবে −l থেকে +l-এর পূর্ণসংখ্যা।
  • mₛ must be +½ or −½ / mₛ হবে +½ অথবা −½।
